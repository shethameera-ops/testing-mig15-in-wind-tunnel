# MiG-15 Wind Tunnel Testing — 3D-Printed Scale Model

Experimental aerodynamic characterization of a 3D-printed MiG-15 scale model in a subsonic wind tunnel.

## Overview
A physical wind tunnel test campaign on a 3D-printed scale replica of the MiG-15 fighter, aimed at experimentally validating aerodynamic characteristics (lift, drag, and stability trends) of the classic swept-wing transonic-era design.

## Methodology
- 3D-printed scale model fabrication
- Subsonic wind tunnel test setup and instrumentation
- Force/moment data acquisition across angle-of-attack sweep
- Comparison against theoretical/historical aerodynamic data for the MiG-15

## Tools
- SolidWorks / CATIA (CAD model preparation for 3D printing)
- Wind tunnel balance & DAQ instrumentation
- Excel / MATLAB (data reduction)
